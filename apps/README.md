# Applications workspace

The canonical sixteen-app topology and ownership boundaries are defined in [BLUEPRINT-APPLICATIONS.MD](../BLUEPRINT-APPLICATIONS.MD). An app directory is not automatically a microservice.

`apps/astronauts/README.md` and `apps/arsy/README.md` are approved planning anchors for the two newly specified runtimes. They are not executable implementations. Other app directories are created only when their first bounded executable slice is ready; do not add empty placeholders or mark scaffolds as working capabilities.
