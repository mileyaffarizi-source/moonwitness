# UI and creative craft

## Use when
Changing product UI, component systems, interaction design, motion, themes, artwork or visual assets.

## Read first
[UI asset blueprint](../../../BLUEPRINT-ASSETS-UI.MD), [design asset governance](../../../BLUEPRINT-DESIGN-ASSETS.MD) and the owning app blueprint. Inspect the existing product before proposing a new direction.

## Anti-slop standard
- Design from the task, users, content, interaction and product world. Do not start from a generic dashboard template.
- Reject interchangeable KPI-card grids, default purple gradients, glow on every surface, gratuitous glassmorphism, random particles, stock hero layouts, oversized empty space and icon decoration.
- Establish a specific visual thesis: hierarchy, grid/composition, typography roles, materials, color behavior, density and motion purpose. Each major choice must support the experience.
- Make MoonWitness feel editorial, lunar and evidence-aware; make operational surfaces dense and legible; keep immersive/game-like elements where they aid exploration, not where they conceal status.
- Use original compositions and deliberate restraint. Distinctiveness is not visual noise. Prefer a few memorable, functional signatures to many effects.
- Use real product states and content. No fake metrics or demo records presented as live.
- Cover loading, empty, error, stale, offline, forbidden, success and responsive states where relevant. Success follows authoritative state, not an animation timer.
- Accessibility is part of the design: semantic structure, keyboard/focus, contrast, reduced motion and text alternatives.

## Asset governance
Track source, license/provenance, version, owner, intended use and review state. Never execute untrusted SVG/HTML. Never depict Allah, Prophet Muhammad or Isa/Jesus visually in any form; textual references only where approved.

## Delivery
Provide an implemented screen/component, not just a moodboard. Verify key viewports, interactions, accessibility and performance; capture screenshots when the task requires visual review.
